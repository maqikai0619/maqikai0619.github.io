# MQK · 个人作品集

纯静态单页作品集，托管在 GitHub Pages，访问地址：<https://maqikai0619.github.io/>

## 结构

- `index.html` —— 页面结构
- `styles.css` —— 样式与动效
- `script.js` —— 项目数据与渲染逻辑

## 后续填链接

打开 `script.js` 顶部的 `projects` 数组，把每个项目的 `demo`（在线演示地址）和 `repo`（GitHub 公开仓库地址）填上即可，对应按钮会自动点亮。

> 注意：`repo` 指向的仓库当前是 private，公开后「源码」链接才对访客可见。
